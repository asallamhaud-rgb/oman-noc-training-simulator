📖 CLI Command Manual & Quick Guide

1. Access & Security (SSH Prep):
• enable -> Enter privileged mode
• configure terminal -> Enter config mode
• username admin privilege 15 secret Pass123
2. VLAN Configuration:
• vlan 20 -> Create/enter VLAN 20
• name TX_Department -> Name the VLAN
3. Port Speed, Duplex & IPs:
• interface GigabitEthernet0/1
• speed 1000 | duplex full
• ip address 192.168.20.1 255.255.255.0
• no shutdown
4. Verification Commands:
• show vlan brief -> List active VLANs
• show ip interface brief -> View port IPs & link states
• show interfaces GigabitEthernet0/1 -> Port stats
5. Saving & Navigation:
• write memory -> Save configuration
• exit -> Step back one mode
