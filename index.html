Enterprise CLI Reference & Manual Guide

Step-by-step CLI commands for interface configuration, slot verification, VLAN setup, and port controls.

1. Enable / Disable IP Interfaces (Shut & Un-shut)

How to disable an interface administratively or bring it back online.

# Enter configuration mode
configure terminal
# Select target port
interface GigabitEthernet 0/1
# Shutdown (Disable) port
shutdown
# Un-shut (Enable) port
no shutdown

2. Increase / Decrease Port Speed

Set interface speed manually (10, 100, 1000 Mbps) or return to auto negotiation.

interface GigabitEthernet 0/1
# Set speed to 1000 Mbps (1 Gbps)
speed 1000
# Force full duplex
duplex full

3. Check & Assign VLANs

Inspect active VLAN database or assign switch ports to specific access VLANs.

# Check active VLAN table
show vlan brief
# Assign interface to VLAN 20
interface GigabitEthernet 0/1
switchport mode access
switchport access vlan 20

4. Inspect Switch Hardware Slots & Inventory

Verify expansion slots, module status, and hardware operational state.

# Check hardware slot modules
show module
# Show port summary across slots
show ip interface brief
